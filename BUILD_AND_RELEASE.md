# Building and Creating the Application (.exe) File\n\nThis guide explains how to build the Windows 10 application and create a release package.\n\n## Prerequisites\n\n- **Windows 10** or later\n- **.NET 8 SDK** (download from https://dotnet.microsoft.com/download/dotnet/8.0)\n- **Visual Studio 2022** (Community Edition is free) OR **Visual Studio Code** with C# extension\n\n## Option 1: Build Using Visual Studio (Easiest)\n\n### Step 1: Clone the Repository\n\n```bash\ngit clone https://github.com/mitplcsoft-byte/FX3U-PLC-Password-Recovery.git\ncd FX3U-PLC-Password-Recovery\n```\n\n### Step 2: Open in Visual Studio\n\n1. Open **Visual Studio 2022**\n2. Click **File → Open → Project/Solution**\n3. Navigate to the cloned folder and select the `.sln` file (or the `FX3UDiagnosticApp.csproj` file)\n4. Wait for the project to load\n\n### Step 3: Build the Project\n\n1. In Visual Studio, go to **Build → Build Solution** (or press `Ctrl+Shift+B`)\n2. Wait for the build to complete (you should see \"Build succeeded\" at the bottom)\n\n### Step 4: Create Release Build\n\n1. Change the build configuration from **Debug** to **Release** (dropdown at the top)\n2. Click **Build → Rebuild Solution**\n3. The `.exe` file will be created in:\n   ```\n   FX3UDiagnosticApp/bin/Release/net8.0-windows/FX3UDiagnosticApp.exe\n   ```\n\n---\n\n## Option 2: Build Using Command Line (Terminal)\n\n### Step 1: Clone and Navigate\n\n```bash\ngit clone https://github.com/mitplcsoft-byte/FX3U-PLC-Password-Recovery.git\ncd FX3U-PLC-Password-Recovery\n```\n\n### Step 2: Build for Release\n\n```bash\ndotnet publish -c Release -f net8.0-windows --self-contained=true -r win10-x64\n```\n\nThis creates a self-contained executable that includes the .NET runtime. The output will be in:\n```\nFX3UDiagnosticApp/bin/Release/net8.0-windows/win10-x64/publish/\n```\n\n### Step 3: Locate the .exe File\n\nNavigate to the publish folder:\n```\nFX3UDiagnosticApp\\bin\\Release\\net8.0-windows\\win10-x64\\publish\\FX3UDiagnosticApp.exe\n```\n\n---\n\n## Option 3: Create a GitHub Release\n\nOnce you have the `.exe` file, you can create an official release on GitHub:\n\n### Step 1: Create a Release Tag in Git\n\n```bash\ngit tag -a v1.0.0 -m \"First Release - Windows 10 RS-232 Diagnostic Tool\"\ngit push origin v1.0.0\n```\n\n### Step 2: Create the Release on GitHub\n\n1. Go to your repository: https://github.com/mitplcsoft-byte/FX3U-PLC-Password-Recovery\n2. Click **Releases** (on the right side of the repo)\n3. Click **Create a new release**\n4. Select the tag you just created (v1.0.0)\n5. Fill in the release details:\n   - **Title**: \"FX3U Diagnostic Tool v1.0.0\"\n   - **Description**: Add release notes\n6. Click **Attach binaries** and upload your `.exe` file\n7. Click **Publish release**\n\nUsers can now download the `.exe` directly from the Releases page.\n\n---\n\n## Option 4: Create an Automated Build Pipeline (GitHub Actions)\n\nAutomatically build and release when you push code.\n\n### Step 1: Create the Workflow File\n\nCreate a new file: `.github/workflows/build-release.yml`\n\n```yaml\nname: Build and Release\n\non:\n  push:\n    tags:\n      - 'v*'\n\njobs:\n  build:\n    runs-on: windows-latest\n    steps:\n      - uses: actions/checkout@v3\n      \n      - name: Setup .NET\n        uses: actions/setup-dotnet@v3\n        with:\n          dotnet-version: '8.0.x'\n      \n      - name: Restore dependencies\n        run: dotnet restore\n      \n      - name: Build Release\n        run: dotnet publish -c Release -f net8.0-windows --self-contained=true -r win10-x64\n      \n      - name: Create Release\n        uses: softprops/action-gh-release@v1\n        with:\n          files: FX3UDiagnosticApp/bin/Release/net8.0-windows/win10-x64/publish/FX3UDiagnosticApp.exe\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\n### Step 2: Push the Workflow\n\n```bash\ngit add .github/workflows/build-release.yml\ngit commit -m \"Add GitHub Actions build pipeline\"\ngit push\n```\n\nNow, whenever you create a new tag, GitHub automatically builds and releases the `.exe`!\n\n---\n\n## Running the Application\n\n1. Double-click `FX3UDiagnosticApp.exe` to launch\n2. The application requires Windows 10 or later\n3. No installation needed (if you used self-contained release)\n\n---\n\n## Troubleshooting\n\n### Issue: \"dotnet: command not found\"\n- Install .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0\n- Restart your terminal after installation\n\n### Issue: Build fails with \"Windows target framework required\"\n- Make sure you're building on Windows 10 or later\n- Or use WSL (Windows Subsystem for Linux) with Windows-specific target\n\n### Issue: Missing dependencies\n```bash\ndotnet restore\n```\n\n---\n\n## Summary\n\n| Method | Effort | Automation |\n|--------|--------|------------|\n| Visual Studio GUI | Low | None |\n| Command Line | Medium | Manual |\n| GitHub Release Upload | Medium | Manual |\n| GitHub Actions | High Setup | Fully Automatic |\n\n**Recommended**: Start with **Option 1 (Visual Studio)** for quick testing, then move to **Option 4 (GitHub Actions)** for professional distribution.\n"
